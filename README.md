## 編集するときの注意

**この3ファイルがポリシーの唯一の原本です。** 他所にコピーを置くと、
古い方が公開されたまま残る事故が起きます。修正はここで行ってください。

- 公開URLは末尾スラッシュ形式(`/privacy/`)です。`.html` を付けると 404 になります。
  App Store Connect と `app/app.config.ts` に登録済みのURLなので、
  `permalink` と `_config.yml` の `baseurl` は変更しないでください。
- 内容を変えたら `最終更新日` も更新してください。
